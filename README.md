# Я рядом — Android

Android-приложение сервиса аренды жилья **«Я рядом»** с интеграцией Telegram.

Цель: предоставить пользователям удобный APK-клиент для поиска и размещения жилья, с авторизацией через Telegram, уведомлениями и быстрым переходом в чаты Telegram.

---

## Технологический стек

### Android (клиент)
| Компонент              | Технология                          |
|------------------------|-------------------------------------|
| Язык                   | Kotlin                              |
| UI                     | Jetpack Compose                     |
| Архитектура            | MVVM + Clean Architecture           |
| Dependency Injection   | Hilt                                |
| Навигация              | Navigation Compose                  |
| Сеть                   | Retrofit + OkHttp / Ktor            |
| Локальная БД           | Room                                |
| Асинхронность          | Coroutines + Flow                   |
| Изображения            | Coil                                |
| Авторизация            | Telegram Login (Bot API / Widget)   |
| Уведомления            | Firebase Cloud Messaging            |

### Backend
| Компонент              | Технология                          |
|------------------------|-------------------------------------|
| Runtime                | Node.js (NestJS) или Python (FastAPI) |
| База данных            | PostgreSQL                          |
| ORM                    | Prisma / TypeORM / SQLAlchemy       |
| Auth                   | JWT + Telegram Auth                 |
| Хранение файлов        | S3-совместимое (Cloudflare R2 / MinIO) |
| Хостинг                | Railway / Render / VPS              |

### Инфраструктура
- CI/CD: GitHub Actions
- Аналитика: Firebase Analytics / PostHog
- Мониторинг: Sentry
